# Sai Chand Sama - Personal Portfolio

A sleek, responsive, and modern personal portfolio website built with React and Vite. Designed with a premium dark mode aesthetic, glassmorphism UI elements, and a dynamic custom cursor. 

## 🚀 Features
- **Dark Mode Aesthetic**: Premium UI with `#050505` background and vibrant neon-teal accents.
- **Interactive Cursor**: Custom tracking cursor that expands when hovering over interactive elements.
- **Glassmorphism Design**: Frosted glass effects on project and experience cards.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewing.
- **Scroll Animations**: Smooth fade and translate animations triggered upon scrolling.

## 🛠️ Technology Stack
- **Framework**: React.js
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Global Styles, Glassmorphism, Animations)
- **Typography**: Google Fonts (Outfit & Inter)

## 📦 Local Installation & Setup

If you'd like to run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saichandsama/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   Make sure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser to view the site.

4. **Build for Production:**
   ```bash
   npm run build
   ```
